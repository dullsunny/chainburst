# 棋盘缩放与落子预览

## 操作

- 棋盘工具栏支持100%–800%缩放、适应全图与拖动查看。放大后可以滚动/触屏滑动查看局部；手掌按钮开启专用拖动模式，此时普通格和空洞均不可落子或编辑。
- 桌面宽度超过 900px 时，本地与联机棋盘框和状态面板顶边对齐。状态栏宽 286–366px；适应全图时棋盘按地图长宽比与视口可用空间等比缩放，预留工具栏和提示区。窄屏的状态栏排在棋盘下方。
- 「辅助设置」可选择自动、几何排列或单颗加数字。自动模式在大图总览时合并显示，缩放至少 160% 且最小格宽达到 23px 后恢复几何排列。显示偏好保存在当前浏览器并用于本地与联机对局。槽位始终分段显示。
- 桌面鼠标进入合法格立即请求完整落子结果；点击仍是真实落子。键盘方向键导航到格子也可以预览。离开合法格、进入洞格、滚动/缩放或关闭预览会取消显示。
- 触屏/手写笔接触合法格即预览，松手保留，再点“确认落子”。接触格子本身的合成click不能落子；拖动、滚动、取消、多指会取消预览。计算失败时提供“直接落子”，不会锁死触屏玩家。关闭预览后恢复普通点击落子。
- 整盘预览用青色虚线和斜纹区别真实棋局，约120–140ms过渡。源格保留真实棋子，净增槽位用青色呼吸、净减槽位用灰色呼吸；预览爆后中立另有灰色呼吸，边框轻颤。下方显示能量变化及连锁或胜利提示。

## 状态与性能

`lib/move-preview.ts`直接调用权威`resolveTurn`并提取最终动态格、胜者和波数，不改输入快照。`workers/move-preview.worker.ts`在独立浏览器Worker计算，预览不请求联机API，不写入真实cells，不影响计分、回合、音效或胜利弹窗。

`hooks/use-move-preview.ts`每个稳定对局上下文保留一个Worker。初始化只发送一次map/snapshot，候选请求只发格子索引；鼠标35ms去抖，触屏立即发起。计算中只保留一个最新候选，缓存本快照最多32个结果；代际和当前索引校验避免旧回包覆盖新预览。map/mode/playerCount/revision/phase/currentPlayer/turnStep/firstMoveIndex改变时失效，禁用和离开时终止线程。

Worker必须经Vite `?worker`导入。Vinext开发模式下`new URL(..., import.meta.url)`曾被处理为file:///，浏览器拒绝启动；不能恢复该写法。`vite-env.d.ts`提供官方Vite模块类型。

v12修复地图数据的线程传输：`createMap`和`createTrihexMap`原先展开整个options，把shapeAt/activeAt/customize回调函数带进GameMap，导致8张内置图在postMessage时抛DataCloneError。两个工厂现在只返回构图后的纯数据，回调仅在构造期间使用。相同问题也会让人机线程降级，现已一并恢复；AI线程也改用Vite `?worker`导入。预览初始化失败时立即终止实例，不遗留闲置线程。

真实`cells`始终决定合法性和实际提交；`predicted.cells`仅用于绘图。双脉冲第二步禁选首格、预充能锁、被动金边、溢出、奇点均沿用引擎规则。

人机调度（2026-11-14）：稳定局面后立即安排 Worker 启动，取消原先额外的120ms启动等待。最短思考展示时间从统一320ms改为入门70ms、标准100ms、困难/大师140ms；这些数值是从回合调度开始计算的下限，不是对算法耗时再次累加。实际等待还包括 Worker 启动、消息传输和动画。异常降级保留用户所选档位、最多使用60ms同步计算；仍显示快速思考提示。离开棋盘、重新开局及状态变化会终止旧Worker和定时器，回包同时校验请求与对局代际。

## 设置与兼容

各格的分段槽位与真实格边平行，旋转格同样适用。预览加能量时青色槽位长亮，减能量时对应槽位长时间变灰，同时在预览栏标出带正负号的变化。减少动态效果时仍保留静态槽位和数值提示。

本地和联机棋盘用实际落子方的颜色淡填上一步落点，格心颜色较亮，淡色波纹从格心向边缘扩散；减少动态效果时只显示静态填色。爆炸清空落点后仍会标记原位置，联机重连时从房间最后一步恢复，开新局时清除。工坊在棋盘外显示选中格编号，读屏仍可播报对战格号和上一步落点。

被动格用琥珀色虚线和锁标记，槽位使用通用配色。预充能格用浅色锁标记。强化边沿真实共边画两条线，外线长且粗，内线短且细，分段槽位更靠中心。鼠标悬停或键盘聚焦可查看容量和传递方向，接收格会高亮。触屏可通过工具栏的查看格子按钮切换到点选查看。详情栏高度固定。

本地设置键为`chainburst-preview-enabled`，默认开启，设置面板可关闭。联机由房主在等待室统一修改`previewEnabled`，应用后所有玩家重新准备；对局中保持该房间设置。旧房间JSON和旧幂等结果缺少字段时默认为true，无D1 schema变更；旧客户端configure不传此字段时保留现有值。

## 验证

自动检查覆盖全地图、三种模式的预览与真实结算一致、输入不可变、预充/被动/双步禁选及终局。几何布局检查每一粒完整位于多边形内。最大 20×20 三六混合图在 280px 拟合宽度下缩放到 800% 能恢复几何显示。v14 旋转格使用真实顶点裁剪和内切圆定位，共边动画与加强边回归见 [地图与密铺维护](MAPS-AND-TILINGS.md)。

[`tests/worker-transport.test.mjs`](../tests/worker-transport.test.mjs) 通过 Node 消息桥运行实际 Worker 入口。v14 覆盖全部 16 张内置地图和八种 20×20 自制图的消息克隆与预览，所有非经典内置图均有人机 Worker 合法落子回归。单独调用主线程的 `calculateMovePreview` 无法覆盖 `postMessage` 的传输故障。

本地API脚本`scripts/check-online-double-step.mjs`同时验证房主权限、预览开关同步/重连、准备重置、双步、同格拒绝、幂等及退出清理。

浏览器实际验证了预览不推进回合或计分、连锁减少槽提示、设置关闭、20×20总览一粒+3转换为放大后的3粒，以及拖动画布不落子。窄视口检查通过；未使用真实手机硬件进行触屏实测，触屏路径经过只读审计和手势防误下检查。
