# 爆炸棋策略分析与人机设计

本分析以项目实际规则为准，先于人机界面接入完成。目标是做公平、能预判完整连锁的人机，不读取未来随机数、不额外注能、不改变容量与胜利条件。

## 1. 真正要争夺的是发动权

棋盘可看成一个有向带权图：格子是节点，真实共边是连接，容量是爆炸阈值，强化边是传递权重。容量、能量、所有权和下一行动者共同决定局面；只看占格数会误判。

满格爆炸先统一扣容量，再统一接收本波传递。同一格超限后保留余量，每波最多爆一次。一次反应必须完全结束才能评价收益。攻击会把接收能量的格子全部变为行动者颜色，敌方储存的能量可能成为自己的下一段连锁。一个己方临界格既可能是武器，也可能是对手的入口。

例：把敌人三个临界格连起来，可以用一次爆炸连续夺走它们；反之，己方高能格若紧贴更早能发动的敌方格，堆能量可能是在给对手积累弹药。

## 2. 经典模式不能按淘汰制思考

获胜要求“唯一颜色，且领地严格超过有效格的一半”。零领地玩家只要还有可落的全空中立格，下次仍能重入。因此：

- 吃掉对手最后一格并不一定获胜；必须同时计算最终覆盖率。
- 占领大量零散低能格可增加落子入口、延缓对手清场，但也可能被一条成熟连锁扫掉。
- 保留安全落脚点有价值，不能把暂时零领地当作已经输棋。
- 爆炸留下的空格可能给对方重新入场，爆完的棋盘比爆炸规模更重要。

## 3. 能量守恒与终局时机

普通格和高容量格每次爆炸总能量守恒；每步注入使总能量增加1。双脉冲每回合最多两步，两步必须选择不同格，每步完整结算连锁。全盘稳定上限为 S = Σ(容量−1)。低容量被动格每爆一次额外产生“邻接数−容量”能量，所以可加速逼近奇点。

当前规则在检测到循环、超过稳定上限或达到既有结算保护上限时，判本次行动者奇点胜。因此奇点是合法终局战术。E接近S是全局时机，而不是某方能量越多就越安全；E≤S也可能循环，必须真实结算，不能仅比较总量。

## 4. 开局、中局、终局

开局：低容量边角更快形成发动点，但不能机械地抢所有角。相邻敌人能否先爆、后续扩散方向、是否能连接第二据点，比固定角落加分更重要。大地图需要兼顾前沿与第二落脚点，避免只给一个孤立据点充能。

中局：让数个己方格接近临界，建立能连续引爆的网络，同时观察敌方谁先发动。进攻应计算完整收益和对手最佳反击；占21格但下一手会被奇点反杀，往往劣于只占几格但保住主动权。预充能中立格是被锁住的公共能量，能由哪条链先点燃决定归属。

终局：优先识别直接胜、避免对手下一手胜，再比较长期结构。经典模式需要检查最后一种敌色与过半条件；疆域赛可直接抢60%，无需耗费回合清空敌方。双脉冲不能直接在同格补2点；可用第一步连锁给第二个据点充能，再在另一格发动第二步。必须计算本回合还剩几步、首步禁选格与中途胜利。

## 5. 几何、特殊格与多人

- 三角格：容量低、战术发展快，边界和瓶颈更敏感。
- 六边格：方向多，中心储能慢但传播范围广；三角棋盘的固定位置表不适用。
- 混合与镂空：按真实邻接搜索，洞边形成的新低容量格和通道比视觉上的“中心”更重要。
- 高容量金边：储能较慢，强化方向可以跨越相邻格临界差；不能把每条边一律当1点。
- 低容量金边：不能主动注入，即使已经归己方也不可直下；是连锁路由和能量增益器。
- 多人：不是双人分数乘人数。玩家各自争胜，过度假设全部对手完美结盟会过分保守；必须跟随真实下一行动者，跳过当前完全无合法着的人，并考虑后手接管前手连锁的风险。

## 6. 算法选择

先用与权威引擎逐步比对的紧凑模拟器，完整结算每一手。它保留实际容量、强化权重、同步波次、超限余量、奇点与下一行动者规则，只省略绘图和动画对象。

当前版本双人采用完整合法回复覆盖的迭代加深、alpha-beta/PVS、置换表、杀手着与历史排序。根节点同样采用 PVS，并从第三层使用围绕上一层得分的愿望窗口；窗口失败必须扩大重搜，不能将上下界当成必胜。先检查根候选的直接胜与一手反杀，再深入计算；只对真正访问的分支做昂贵的连锁结算，使用增量双指纹和子局面缓存复用结果。多人采用完整Max-N：每个节点按当前行动者自身利益选择，不把其他玩家当完美联盟。

2026-11-14 的模拟器使用本波源格和接收格构建下一波候选，增量维护领地计数，并使用所有权/能量的无损字符编码检测循环，保留原保护上限。困难和大师在根局面距稳定上限不超过 8 点时，对搜索叶子再检查行动者是否下一步直接获胜；仅真实结算出的胜利产生终局分数，不作“可以停手”的假设。`depth` 记录完成的常规层数，终局叶子检查可能额外看到一步。

v8曾在深层按静态分只保留12个候选，漏掉安静防守后又把乐观结果当成必胜，提前结束思考。v9已移除该束裁剪；“胜负大分”来自实际终局且覆盖合法防守。未完成的迭代不覆盖上次完整结果。模拟器与真实引擎共用波次/传递保护上限，增量指纹另有重建一致性回归。

评估兼顾成熟据点、连通临界格的先发动权、敌方接管风险、能量与可落点，避免只偏好铺满低能量的空格。疆域赛仍强调领地竞速。终局分数严格压过所有静态收益；近稳定上限时提高终局搜索深度目标。搜索在独立Worker执行，离开/重开时终止旧请求。

四档：入门用轻量排序与随机探索，仅模拟可能直接获胜的候选，预算18ms；标准最多3层（双脉冲4层）/120ms；困难最多9层/700ms；大师通常最多16层/2200ms，接近能量上限时提高深度目标。入门决策标记为 `heuristic`，其他档为 `full-width`。以上预算按每步计，实际完成层数取决于设备、地图和连锁复杂度。不同档都遵循相同规则。有限思考时间仍不能保证全局数学最优；大地图和多人会降低可完成深度。

v10起双脉冲每步只加1点，首步后仍是同一行动者，第二步不能选首步格；若无其他合法格则结束回合。搜索模拟器完整保留这些状态，置换键和子局面缓存键均包含剩余步数与首步位置，避免相同棋盘但不同禁选格串缓存。下文v8/v9双脉冲数据使用旧版同格2能量规则，仅作历史记录；当前新旧AI基准改为对照 `tests/fixtures/ai-v14.ts`（源码基线66b879b），因此重新覆盖当前双脉冲。

## 7. 验证标准

不能仅用“看起来会占角”说明强度。应包含：全地图/模式模拟器与权威引擎差分、直接经典胜、强化边胜着、E≤S循环奇点、拒绝贪大避开一手杀、零领地重入、被动/锁定格合法性，以及不同难度交叉对战。统计需要同时报告地图、模式、先手轮换和样本量，不把少量自战当成人类棋力等级。

## 8. v8历史实测（2026-10-25）

常驻测试套件共30项通过，其中AI差分测试逐步比较了16,691个回合（全部内置图、三种模式、2/3/4/5/6人）。另做四种20×20自制密铺、六人、被动/预充能格的144回合差分和48次合法决策检查。后续可运行 `npm test` 复核规则，运行 `npm run test:ai-benchmark` 重做8局快速强度基准；时间预算搜索在不同CPU上可能完成不同深度，结果不保证逐局重现。

战术题：6×6一局面中，标准档贪心可抢21格但立即被反杀，安全着只有两个远端空格。大师在25/50/100毫秒测试预算下均选中安全着，并找到后续胜机。另通过唯一经典胜着、高容强化边唯一胜着、总能量未超稳定上限的循环奇点等题目。
